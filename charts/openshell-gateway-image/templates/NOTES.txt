openshell-gateway-image deployed.

The ImageStream and BuildConfig are ready. To trigger a build:

  make build-gateway-image
  # or: oc start-build {{ (split ":" .Values.output.imageStreamTag)._0 }} -n {{ .Release.Namespace }} --follow

Follow build progress:

  make build-gateway-image-follow
  # or: oc logs -f bc/{{ (split ":" .Values.output.imageStreamTag)._0 }} -n {{ .Release.Namespace }}

Use the image in the gateway chart:

  make gateway-from-image

Or manually:

  helm upgrade --install openshell-gateway ./openshell-gateway \
    --set image.mode=containerDisk \
    --set image.containerDisk=image-registry.openshift-image-registry.svc:5000/{{ .Release.Namespace }}/{{ .Values.output.imageStreamTag }} \
    --set sshPublicKey="$(cat ~/.ssh/id_ed25519.pub)"
