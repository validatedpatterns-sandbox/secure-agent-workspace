openshell-gateway deployed.

Verify the gateway is ready:

  helm test {{ .Release.Name }} -n {{ .Release.Namespace }} --logs

SSH into the gateway:

  ssh-keygen -R "vm.{{ include "openshell-gateway.fullname" . }}.{{ .Release.Namespace }}"
  virtctl -n {{ .Release.Namespace }} ssh cloud-user@vm/{{ include "openshell-gateway.fullname" . }}
